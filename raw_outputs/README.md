# Raw outputs

Unedited output of one full pipeline run, as written by `coldopen run`:

- `sample-show/` is *The Lamp-Keeper's Daughter*, an invented 14-episode show, run with the offline stand-in models.
  It holds every stage artifact (`00_` to `08_`), every model call (`llm_calls/`), `promos.csv`, `promos.md`,
  `edl/*.edl` and `run_report.json`.
- `BUILD_LOG.md` lists each place the AI-generated work was wrong, how it was caught and the fix.

The outputs for the client's real scripts are not published here, because they contain the scripts themselves.
They are available to reviewers on request.
